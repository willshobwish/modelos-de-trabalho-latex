  \textbf{ABSTRACT}
\end{center}

This guide uses its own source document to introduce the most common commands required to write an article in \LaTeX. Its examples cover modular organization, sections, text formatting, lists, footnotes, quotations, cross-references, mathematics, tables, figures, algorithms, source-code listings, citations, and bibliographies. Each feature is paired with a short explanation so that the document can serve both as a quick reference and as a starting point for new academic papers.
