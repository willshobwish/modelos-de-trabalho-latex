\begin{center}
    \uppercase{Como usar este guia}
\end{center}

Este documento é um exemplo compilável. Cada tópico apresenta um comando \LaTeX,
mostra seu código e, quando útil, exibe o resultado logo em seguida. Para adaptar o
modelo, comece pelos dados no início de \texttt{main.tex}; depois substitua os
exemplos nos arquivos da pasta \texttt{sections} pelo conteúdo do relatório.

Os comandos são organizados por finalidade: estrutura do projeto, formatação de
texto, listas, figuras, tabelas, equações, código-fonte, referências cruzadas,
siglas e referências bibliográficas.
